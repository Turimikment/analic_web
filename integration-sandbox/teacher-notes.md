# Teacher notes

Core message for students:

A system analyst translates business flow into contracts between systems.

The student should not memorize technologies. The student should recognize interface type, payload, storage role, failure point and owner team.

Recommended demo order:

1. Start from business story.
2. Open REST contract.
3. Show database tables.
4. Show cache example.
5. Show event example.
6. Show object storage example.
7. Show WSDL.
8. Search logs by request_id.
