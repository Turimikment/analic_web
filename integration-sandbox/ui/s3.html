S3 / object storage

Case: attach receipt or return photo

The student learns bucket, object key, metadata and signed download links.

Business situation

A customer uploads a receipt or damaged item photo. The file is stored in object storage. The database stores metadata and object key.

Object key example

orders/ord-10001/files/receipt.pdf
returns/ord-10001/photos/damage-001.jpg

Metadata example

{
  "order_id": "ord-10001",
  "object_key": "orders/ord-10001/files/receipt.pdf",
  "file_name": "receipt.pdf",
  "mime_type": "application/pdf",
  "size_bytes": 245000
}

Student tasks

  1. Find file metadata in database.
  2. Find object key in storage browser.
  3. Explain why file bytes are not stored in the order table.
  4. Explain why public bucket is dangerous.

Analyst takeaway

For files, analyst should specify file type, size limit, storage key convention, access rules and retention period.
