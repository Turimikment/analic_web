Integration Sandbox

Safe training area for future system analysts: REST, SOAP/WSDL, database, Kafka, Redis, S3 and logs in one order processing case.

Flow: REST creates order -> DB stores state -> Redis caches status -> Kafka publishes event -> S3 stores file -> SOAP sends delivery request -> logs connect everything by request_id.

REST / Swagger

Read OpenAPI contract and send POST /orders.

Database

Find order row, items and file metadata.

Redis

Check cached order status and TTL.

Kafka

Inspect order_created event and discuss idempotency.

S3

Upload receipt or return photo and find object key.

SOAP / WSDL

Read legacy delivery contract and XML operation.

Logs

Search by request_id and restore the full chain.
