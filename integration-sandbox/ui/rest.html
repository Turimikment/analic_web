REST / Swagger

Case: create an order through API

The student reads the OpenAPI contract, sends a request and explains request, response, headers and validation errors.

Business situation

A customer presses Buy. The frontend calls backend endpoint POST /orders. Backend creates order and returns its identifier.

Request example

POST /orders
X-Request-Id: req-2026-0001
Content-Type: application/json

{
  "customer_id": "usr-777",
  "items": [{"sku": "SKU-001", "quantity": 2}],
  "delivery_city": "City"
}

Response example

201 Created
{
  "order_id": "ord-10001",
  "status": "CREATED",
  "request_id": "req-2026-0001"
}

Student tasks

  1. Find required fields in OpenAPI.
  2. Explain why X-Request-Id is passed in headers.
  3. Explain what happens if quantity is missing.
  4. Describe success and validation error scenarios.

Analyst takeaway

REST contract is not just a URL. It is a promise about method, path, headers, body, status codes and error format.
