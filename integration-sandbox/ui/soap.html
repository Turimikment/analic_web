SOAP / WSDL

Case: legacy delivery service

The student opens WSDL and learns where operations, messages and XML fields are described.

Business situation

Delivery partner is an old enterprise system. It accepts only SOAP request CreateDelivery.

SOAP body example

<CreateDeliveryRequest>
  <requestId>req-2026-0001</requestId>
  <orderId>ord-10001</orderId>
  <city>City</city>
  <address>Main street 1</address>
</CreateDeliveryRequest>

Student tasks

  1. Open delivery.wsdl.
  2. Find operation CreateDelivery.
  3. Find required fields.
  4. Explain how WSDL differs from OpenAPI.

Analyst takeaway

SOAP is common in legacy enterprise integrations. Analyst should not fear XML: WSDL is just a formal contract.
