Database

Case: find order data in tables

The student sees how business objects are stored: order, items and file metadata.

Business situation

After REST request backend inserts rows into orders and order_items. Files are not stored as binary content in the order row.

Useful query

SELECT o.order_id, o.status, o.request_id, i.sku, i.quantity
FROM orders o
JOIN order_items i ON i.order_id = o.order_id
WHERE o.order_id = 'ord-10001';

File metadata query

SELECT order_id, object_key, file_name, mime_type, size_bytes
FROM order_files
WHERE order_id = 'ord-10001';

Student tasks

  1. Find the primary key of the order.
  2. Explain why order items are in a separate table.
  3. Find request_id and connect it with logs.
  4. Explain why file storage uses object_key.

Analyst takeaway

The analyst should understand data ownership: transactional state is in database, large files are in object storage, cache is temporary.
