📋 Задание: придумай CRUD

Что нужно сделать

Придумай простую сущность, с которой пользователь сможет выполнять CRUD-операции. Например: заметки, задачи, книги, товары или питомцы.

  1. Определи, какие данные будут храниться у сущности.
  2. Придумай REST endpoint'ы для Create, Read, Update, Delete.
  3. Опиши JSON для запросов и ответов.
  4. Спроектируй таблицу БД, в которой будут храниться данные.
  5. Свяжи поля REST с полями таблицы БД.
Пример: если выбрал «Заметки», можно начать с POST /api/v1/notes, а в БД создать таблицу notes. Не копируй пример целиком — придумай свой вариант.
