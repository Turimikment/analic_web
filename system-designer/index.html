📋 Задача: список адресов доставки

Бизнес-требование

В личном кабинете интернет-магазина пользователь должен иметь возможность сохранять адреса доставки, чтобы не вводить адрес заново при каждом заказе.

Пользователь должен уметь добавить новый адрес, посмотреть список своих адресов, изменить сохранённый адрес и удалить его.

Данные адреса

Для каждого адреса необходимо хранить: город, улицу, дом, квартиру и комментарий для курьера. Комментарий необязательный.

У каждого адреса должен быть уникальный идентификатор. Адрес должен принадлежать конкретному пользователю.

Что требуется от аналитика

  1. Спроектировать REST API для создания, получения, изменения и удаления адресов.
  2. Определить request и response для каждого endpoint.
  3. Предусмотреть основные HTTP-коды успешных и ошибочных ответов.
  4. Спроектировать таблицу БД для хранения адресов.
  5. Связать поля REST API с полями таблицы БД.
Важно: готового контракта здесь нет. Выбери HTTP-методы, URL, структуру JSON и модель хранения самостоятельно — как это сделал бы системный аналитик перед передачей задачи разработчику.
