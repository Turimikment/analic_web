Найдите свой ID через Swagger

Используйте Swagger API, чтобы найти ID своего аккаунта

Инструкция:

  1. Перейдите в Swagger документацию
  2. Найдите раздел Accounts
  3. Используйте метод GET /api/accounts
  4. Нажмите кнопку Try it out затем Execute
  5. В ответе найдите свою "заячью кличку" (username)
  6. Скопируйте ID, соответствующий вашему имени пользователя
