Как пользоваться чатиком

1
Нажми “Подключиться”.
Сайт создаст consumer instance и подпишет его на topic.
2
Напиши сообщение слева.
Левая колонка — это producer. Он отправляет событие в Aiven Kafka.
3
Смотри правую колонку.
Правая колонка — consumer. Он читает сообщения через consumer group.
4
Открой Kafka UI.
Проверь topic, сообщения, consumer group, offset и lag.

Что показывает тренажёр

ЭлементСмысл
ProducerСервис, который отправляет событие в Kafka.
TopicЛог событий. В нашем стенде это trainer-chat.
ConsumerСервис, который читает события из topic.
Consumer GroupГруппа читателей. Kafka хранит offset для группы.
OffsetПозиция сообщения внутри партиции.
LagСколько сообщений consumer ещё не обработал.

Как пользоваться Kafka UI

Kafka UI — это админка для просмотра Kafka-кластера. В ней можно показать студентам, что сообщения реально попадают в Kafka.

  1. Открой Kafka UI по кнопке выше.
  2. Зайди в Topics.
  3. Открой topic trainer-chat.
  4. Посмотри вкладку сообщений и партиций.
  5. Открой Consumer Groups и найди trainer-chat-group.
  6. Покажи offset и lag после отправки сообщений из тренажёра.
Kafka UI лучше использовать как просмотрщик. Не удаляй topic и consumer group во время занятия.

Что происходит под капотом

Браузер не подключается к Kafka напрямую. Он обращается к Flask backend:

EndpointЧто делает
/kafka/api/connectСоздаёт consumer и подписывает его на topic.
/kafka/api/sendОтправляет событие support.message.created в Kafka.
/kafka/api/pollЧитает новые сообщения через consumer.
/kafka/uiОткрывает внешний Kafka UI.
Секреты Aiven лежат только на сервере в env-переменных. Студент в браузере их не видит.
